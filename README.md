# 🚀 Skill_UP

> A Full Stack MERN Platform for B.Tech Students with Aptitude Prep, Learning Modules, DevHub, Jobs & Career Support.

🌐 **Live Demo:**  
https://skill-up-frontend.onrender.com

---

# 📌 Overview

Skill_UP is a complete student-focused career preparation platform built using the MERN Stack.  
The platform helps students improve technical skills, practice aptitude questions, explore jobs, upload projects, and access curated learning resources — all in one place.

This project was developed to solve the problem of scattered preparation resources by creating a centralized learning and career ecosystem for engineering students.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Hks100524/Skill_UP.git
```

---

## 2️⃣ Backend Setup

```bash
cd backend
npm install
```

Create `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
EMAIL_USER=your_email
EMAIL_PASS=your_password
OPENROUTER_API_KEY=your_api_key
```

Run Backend:

```bash
npm run dev
```

---

## 3️⃣ Frontend Setup

```bash
cd frontend
npm install
```

Create `.env` file:

```env
VITE_API_URL=http://localhost:5000
```

Run Frontend:

```bash
npm run dev
```
